## 📂 Estructura del Directorio

El repositorio está organizado por cada Trabajo Práctico (TP), manteniendo separados los informes teóricos de las simulaciones (por ejemplo, archivos de Packet Tracer o scripts).

```text
📦 Comunicaciones de Datos-TPs
 ┣ 📂 TP1-Fundamentos_y_PacketTracer
 ┃ ┣ 📜 Informe_TP1.pdf
 ┃ ┣ 📜 topologia_red.pkt
 ┃ ┗ 📜 referencias.md
 ┣ 📂 TP2-[Tema_del_TP2]
 ┗ 📜 README.md
```

## 🚀 Metodología y Uso
Para la gestión de este proyecto utilizamos el flujo de trabajo estándar de Git:
1. Asegurarse de tener configurado correctamente el `.gitignore` para evitar subir archivos temporales de simuladores o compilaciones.
2. Realizar *commits* descriptivos detallando qué punto del laboratorio se resolvió.
3. Los informes finales se suben en formato PDF para facilitar su corrección por parte de la cátedra.
